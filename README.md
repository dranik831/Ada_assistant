# Ада (Ada) — Мультимодальный автономный ИИ-ассистент

Проект представляет собой автономную цифровую личность, которая работает напрямую через пользовательский аккаунт Telegram с использованием библиотеки Telethon. В отличие от обычных чат-ботов, Ада обладает собственным эмоциональным фоном, динамической системой отношений к собеседникам и способностью автономно инициировать действия.

## 📌 Ключевые возможности

* **Эмоциональная система**: Состояние Ады (счастье, гнев, уверенность, энергия, стресс и другие параметры) математически оценивается по шкале от 0 до 100. Эмоции динамически меняются от контекста общения и постепенно «остывают», возвращаясь к базовому уровню.


* **Социальная репутация и иерархия**: Локальная база данных SQLite отслеживает метрики доверия, привязанности, уважения и раздражения для каждого отдельного пользователя. На основе этих данных алгоритм определяет статус собеседника: от врага до лучшего друга, что напрямую влияет на тон ответов. Высший приоритет и абсолютное уважение закреплены за Создателем (администратором).


* **Проактивная автономность**: Агент не просто отвечает на сообщения, но и способен писать первым после заданного интервала тишины. При этом система учитывает настраиваемые «тихие часы», блокируя инициативу ночью или во время отдыха.


* **Управление окружением (Tools)**: ИИ обладает набором инструментов для чтения и записи файлов, извлечения контента из веб-страниц, поиска по контактам и создания событий в календаре. По запросу Создателя агент может напрямую выполнять системные команды в терминале операционной системы (PowerShell/Bash).


* **Умная работа с контекстом**: При переполнении контекстного окна старые сообщения автоматически сжимаются (суммаризируются) через LLM, а важные детали переносятся в базу долговременной памяти.



## 🚀 Архитектура и стек технологий

Проект написан на Python и модульно разделен на ключевые узлы принятия решений:

* **LLM Core (`llm.py`)**: Обработка логики и вызов функций (Function Calling) через `AsyncOpenAI`. Поддерживается работа как с моделями Gemini, так и с OpenAI-совместимыми API.


* **База данных (`database.py`)**: Асинхронное взаимодействие (`aiosqlite`) с таблицами пользователей, глобальной памяти, логов размышлений, задач и событий.


* **Telegram Layer (`main.py`)**: Работа в режиме Userbot. Сообщения, присланные подряд, склеиваются в единый смысловой блок для экономии токенов и более естественного ответа. Агент также умеет анализировать групповые чаты и вмешиваться в диалог с определенной долей вероятности.


* **Оркестратор (`brain.py`)**: Собирает данные о времени, статусе собеседника, текущих эмоциях Ады и выгрузке из памяти, формируя итоговый системный промпт для LLM перед каждым ответом.

## 🛠 Установка и запуск

1. **Клонируйте репозиторий и создайте виртуальное окружение:**
```bash
git clone <URL_репозитория>
cd <имя_папки>
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate

```


2. **Установите зависимости:**
```bash
pip install -r requirements.txt

```


*(Убедитесь, что в requirements.txt добавлены `telethon`, `aiosqlite`, `openai`, `aiohttp`, `trafilatura`, `python-dotenv`)*
3. **Настройка окружения:**
При первом запуске скрипт автоматической настройки создаст файл `.env`. Откройте его и заполните необходимые ключи:


* `TG_API_ID` и `TG_API_HASH` (получить на my.telegram.org; используйте собственные значения).
* `TG_PHONE` (номер телефона аккаунта, которым будет управлять ИИ).
* `GEMINI_API_KEY` или `LLM_API_KEY` (в зависимости от выбранного провайдера).


* `ADMIN_USERNAME` (ваш Telegram юзернейм без @, для получения прав Создателя).




4. **Запуск:**
```bash
python main.py

```


При первом запуске потребуется ввести код подтверждения от Telegram для авторизации сессии. После успешного входа Ада начнет отслеживать входящие сообщения и анализировать контекст диалогов.
