# Ада (Ada) — Автономный ИИ-ассистент с памятью и расписанием

Проект представляет собой автономную цифровую личность, которая работает напрямую через пользовательский аккаунт Telegram с использованием библиотеки Telethon. В отличие от обычных чат-ботов, Ада обладает собственным эмоциональным фоном, динамической системой отношений к собеседникам, долговременной памятью с версионированием фактов и способностью автономно инициировать действия.

> Актуальная разработка ведётся в ветке **alpha**, стабильная версия — **beta**.

## 📌 Ключевые возможности

* **Эмоциональная система**: Состояние Ады (счастье, гнев, уверенность, энергия, стресс и другие параметры) математически оценивается по шкале от 0 до 100. Эмоции динамически меняются от контекста общения и постепенно «остывают», возвращаясь к базовому уровню.

* **Социальная репутация и иерархия**: Локальная база данных SQLite отслеживает метрики доверия, привязанности, уважения и раздражения для каждого отдельного пользователя. На основе этих данных алгоритм определяет статус собеседника, что напрямую влияет на тон ответов. Уважение к Создателю по умолчанию — 85, и оно меняется только по явной команде самого Создателя (команда `уважение` в режиме редактирования или инструмент `set_person_respect`) — Ада не «обожает» Создателя, а уважает его как руководителя проекта и может возражать.

* **Проактивная автономность**: Агент не просто отвечает на сообщения, но и способен писать первым после заданного интервала тишины. При этом система учитывает настраиваемые «тихие часы», блокируя инициативу ночью или во время отдыха.

* **Расписание колледжа (УКРТБ)**: Ада подключена к учебному порталу study.ukrtb.ru через открытый JSON-API. Она умеет показывать расписание группы/преподавателя/аудитории на любую дату («сегодня», «завтра» или ISO-дату), знает расписание звонков, кэширует ответ локально (data/schedule_cache.json) и каждое утро отправляет Создателю расписание его группы на день.

* **Секретарь и планирование**: Напоминания (в том числе повторяющиеся — `daily`, `weekly`, `weekdays`), локальный календарь с поддержкой таймзон в датах, запросы на встречи с Создателем.

* **Долговременная память с версионированием**: Факты хранятся с областью видимости (global/person/group), важностью, уверенностью, источником и сроком действия. Новый факт, противоречащий старому, помечает его как `superseded`, все изменения журналируются в `memory_history`. Старый слой `global_memories` автоматически мигрируется в `memory_items` при первом запуске.

* **Надёжность**: Единая исходящая очередь сообщений с обработкой Telegram FloodWait, блокировки обработки на каждый чат (сообщения одного чата никогда не обрабатываются параллельно), супервизор `run.py`, который перезапускает Аду при падении с нарастающей паузой.

* **Умная работа с контекстом**: При переполнении контекстного окна старые сообщения автоматически сжимаются (суммаризируются) через LLM, а важные детали переносятся в базу долговременной памяти. Для групп можно задавать локальные правила и Ада отслеживает последние темы обсуждения.

## 🚀 Архитектура и стек технологий

Проект написан на Python и модульно разделен на ключевые узлы принятия решений:

* **LLM Core (`llm.py`)**: Обработка логики и вызов функций (Function Calling) через `AsyncOpenAI`. Поддерживается работа как с моделями Gemini, так и с OpenAI-совместимыми API, с автоматическим переключением на Gemini при сбоях основного провайдера (таймауты, HTTP 429/5xx).

* **База данных (`database.py`)**: Асинхронное взаимодействие (`aiosqlite`) с таблицами пользователей, памяти `memory_items` + журнала `memory_history`, логов размышлений, задач и событий.

* **Telegram Layer (`main.py`)**: Работа в режиме Userbot. Сообщения, присланные подряд, склеиваются в единый смысловой блок. Исходящие сообщения идут через централизованную очередь с обработкой FloodWait.

* **Оркестратор (`brain.py`)**: Собирает данные о времени, статусе собеседника, текущих эмоциях Ады, локальных правилах чата и выгрузке из памяти, формируя итоговый системный промпт для LLM перед каждым ответом.

* **Портал УКРТБ (`schedule_api.py`)**: Клиент учебного портала study.ukrtb.ru: списки групп/преподавателей/аудиторий, расписание на дату, расписание звонков, локальный кэш.

* **Супервизор (`run.py`)**: Обёртка процесса с автоматическим перезапуском при сбоях.

## 🛠 Установка и запуск

1. **Клонируйте репозиторий и создайте виртуальное окружение:**
```bash
git clone https://github.com/dranik831/Ada_assistant
cd Ada_assistant
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройка окружения:**
При первом запуске скрипт автоматически создаст файл `.env`. Откройте его и заполните необходимые ключи:
* `TG_API_ID` и `TG_API_HASH` (получить на my.telegram.org; используйте собственные значения).
* `TG_PHONE` (номер телефона аккаунта, которым будет управлять ИИ).
* `GEMINI_API_KEY` или `LLM_API_KEY` (в зависимости от выбранного провайдера).
* `ADMIN_USERNAME` (ваш Telegram юзернейм без @, для получения прав Создателя).
* `UKRTB_GROUP_ID` и `UKRTB_GROUP_LABEL` — группа учебного портала УКРТБ для расписания (по умолчанию подставлена группа из разработки).

4. **Запуск:**
```bash
python main.py    # напрямую
python run.py     # через супервизор с автоперезапуском
```

При первом запуске потребуется ввести код подтверждения от Telegram для авторизации сессии. После успешного входа Ада начнет отслеживать входящие сообщения и анализировать контекст диалогов.

### Команды режима редактирования (только Создатель)

Вход: `редактирование 8338` в личном чате, выход: `выйти`.

Основные команды: `эмоции`, `состояние`, `память`, `память история`, `уважение <id> <0..100>`, `категория <id>`, `правило <chat_id> <текст>`, `календарь добавить/удалить`, `задачи`, `задача отменить <id>`, `расписание сегодня|завтра` (УКРТБ), `расписание обновить`, `расписание импорт <JSON>`, `запросы`, `имя`, `био`, `промпт`, `техработы`, `перезапуск`.
